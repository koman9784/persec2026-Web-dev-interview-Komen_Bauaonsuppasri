## โจทย์แต่ละข้อ

1. **ตรวจสอบวงเล็บ — `src/bracketValidator.ts`**  
   ตรวจสอบว่าวงเล็บ `()`, `[]` และ `{}` เปิดและปิดได้ครบตามลำดับหรือไม่ โดยใช้ stack เก็บวงเล็บที่ยังไม่ถูกปิด แล้วคืนค่า `true` หรือ `false`

2. **เรียงข้อมูลตามรูปแบบ — `src/customSort.ts`**  
   เรียงข้อความที่ประกอบด้วยตัวอักษรนำหน้า ตัวเลข และข้อความต่อท้าย ตามลำดับ: ตัวอักษรนำหน้า, ค่าตัวเลขจากน้อยไปมาก และข้อความต่อท้ายตามตัวอักษร

3. **Autocomplete — `src/autocomplete.ts`**  
   ค้นหาข้อความที่มีคำค้นโดยไม่แยกตัวพิมพ์เล็ก-ใหญ่ จัดลำดับคำที่ขึ้นต้นด้วยคำค้นก่อน คำที่มีคำค้นอยู่ตรงกลางถัดมา และคำที่ลงท้ายด้วยคำค้นทีหลัง จากนั้นจำกัดจำนวนผลลัพธ์ตามที่กำหนด

4. **แปลงเลขโรมัน — `src/romanNumerals.ts`**  
   แปลงจำนวนเต็มช่วง 1–3999 เป็นเลขโรมัน และแปลงเลขโรมันกลับเป็นจำนวนเต็ม โดยตรวจสอบรูปแบบมาตรฐานก่อนคืนผลลัพธ์

5. **เรียงตัวเลขจากมากไปน้อย — `src/descendingOrder.ts`**  
   นำหลักของจำนวนเต็มบวกมาเรียงจากมากไปน้อย แล้วรวมกลับเป็นจำนวนเต็ม เช่น `1989` ได้ `9981`

6. **ลำดับ Tribonacci — `src/tribonacci.ts`**  
   สร้างลำดับโดยนำ 3 ค่าก่อนหน้ามาบวกกัน ค่าเริ่มต้นที่ให้มามีได้ไม่เกิน 3 ค่า และเติมศูนย์ให้ครบหากมีค่าน้อยกว่า 3 ค่า โดย `n` คือจำนวนสมาชิกทั้งหมดที่ต้องการ

## การทดสอบใน `src/index.ts`

ไฟล์นี้นำเข้าฟังก์ชันทั้ง 6 หัวข้อ แล้วเรียกใช้ฟังก์ชันช่วย `test(name, actual, expected)` เพื่อเปรียบเทียบผลจริงกับผลที่คาดหวังด้วย `JSON.stringify` หากตรงกันจะแสดง `✅ PASS` หากไม่ตรงจะแสดง `❌ FAIL` พร้อมพิมพ์ผลจริงและผลที่คาดหวัง

ตัวอย่างที่เรียกทดสอบในไฟล์:

- วงเล็บ `([{}])` ต้องถูกต้อง และ `([)]` ต้องไม่ถูกต้อง
- เรียง `TH19`, `SG20`, `TH2` เป็น `SG20`, `TH2`, `TH19`
- ค้นหา `th` จากรายการตัวอย่าง โดยให้ผลลัพธ์ไม่เกิน 2 รายการ
- แปลง `1989` เป็น `MCMLXXXIX` และแปลงกลับเป็น `1989`
- เรียงหลักของ `1989` เป็น `9981`
- สร้าง Tribonacci จาก `[1, 1, 1]` ให้ครบ 6 ค่า

รันตัวอย่างทดสอบใน `index.ts` ด้วย:

```bash
npm start
```

ตรวจสอบชนิดข้อมูล TypeScript ด้วย:

```bash
npm run typecheck
```
